# Contributing

Thanks for your interest in contributing to Sourced Consulting's SEO tools.

## How to Contribute

1. Fork the repo and create a feature branch (`git checkout -b feature/your-tool`)
2. Add your script or resource with clear inline comments
3. Test it runs without error: `python scripts/your_script.py --help`
4. Open a pull request with a clear description of what the tool does and a usage example

## What We're Looking For

- Python scripts that solve a real SEO problem for Australian small businesses
- CSV/JSON parsers for Search Console, GSC, or Ahrefs exports
- Content analysis tools (keyword density, readability, highlight issues)
- Local SEO utilities (GMB export cleaners, citation checkers)
- Resources: meta tag templates, word-count benchmarks, schema snippets
